# ghtb-prices-history

Plataforma de valoración de archivos y actualizaciones de software.

[Ver el sitio](https://lfarmas4.github.io/ghtb-prices-history/)

Incluye Organizations, Usage, Payment history, Despliegues, configuración de imágenes y tarifas, y el historial principal completo de CrossBox (1.194 commits) y FitCode (340 commits) hasta la instantánea de octubre de 2026. Las valoraciones se distribuyen por líneas añadidas y eliminadas; no representan pagos históricos verificados.

Los archivos, ajustes y pagos introducidos por el visitante se mantienen en su navegador. El checkout no realiza cargos ni despliega aplicaciones reales.

El paquete ZIP contiene el sitio estático completo. El flujo de GitHub Actions lo extrae y publica en GitHub Pages. No se incluyen credenciales, código fuente de las aplicaciones privadas ni datos locales del navegador.

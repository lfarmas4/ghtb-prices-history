# CodeWeight

CodeWeight is a static, browser-only interface. Its local deployment and checkout flows are simulations; they make no network calls to deploy software or process real payments. Records are stored in this browser on this device.

The included histories cover 1,194 CrossBox and 340 FitCode mainline commits. The overview's supplied 2026 monthly values total USD 10,591 for CrossBox and USD 1,880 for FitCode (USD 12,471 combined). These are modeled cost allocations, not verified historical payments.

The ATR System and PWR Games sample archives are fingerprint-recognized at USD 150 and USD 350 by default. Those package rates are configurable. Other files use the configured size-based pricing formula.

The billing view starts with a USD 300 budget, USD 260 usage, and USD 40 available budget. It separately shows USD 130 of ledger credit/balance; the ledger figure is not a claim that the budget is exceeded. These are browser-only records, not processed payments.

New payment tracking begins at 2026-10-29 09:54:42 UTC. Older records are excluded from new-spend totals. Deleting an entry removes it from totals; restoring it adds it back.

The saved payment display uses a masked card ending in 0388. The package contains no card number.

Deployment and payment history records support soft deletion and restoration.

The source repositories are private. Commit links may require an authorized GitHub account. Do not add credentials or personal data to this package.
